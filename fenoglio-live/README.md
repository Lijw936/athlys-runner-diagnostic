# Fenoglio live transcription

Captures public YouTube audio if accessible and runs local faster-whisper on a GitHub runner. No subtitle dependency. Transcripts are provisional, timestamps start at capture start, speaker attribution and any quoted material must be checked manually. Runs on 17-18 November 2026 only; workflow_dispatch can be used manually after those dates. Scheduled runs may be delayed and may miss segments. YouTube can block runner access. Artifacts retained for seven days; no article is automatically published.
